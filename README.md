## Project Description

This project is a practical exercise for Computer Programming I. It introduces the fundamentals of Java programming through a simple program that displays text and personal academic information.

## What the Program Does

- Prints a welcome message.
- Introduces Java programming.
- Displays the student's information.
- Shows the course details and learning objective.

## Requirements

To run this project, you need:

1. Java Development Kit (JDK).
2. A code editor such as Visual Studio Code.
3. Command Prompt or Terminal.

## How to Compile and Run

From the project root directory, run:

```bash
javac week02/Helloworld.java
java week02.Helloworld
```
